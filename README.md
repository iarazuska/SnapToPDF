### ✨ Features

| Feature | Description |
|---|---|
| 📥 **Drag & Drop** | Drag images directly into the app |
| 🖼️ **Thumbnails** | Preview every image before converting |
| 🔢 **Reorder** | Move images up and down to set the page order |
| 🗑️ **Remove items** | Delete individual images or clear the whole list |
| 📄 **Multi-page PDF** | Combine multiple images into a single PDF |
| ℹ️ **Image info** | See dimensions, file size and format for each image |
| 🎨 **Dark UI** | Clean dark interface |

### 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/iarazuska/SnapToPDF.git

# Navigate to project folder
cd SnapToPDF

# Install dependencies
pip install pillow tkinterdnd2

# Run the app
python main.py
```

---

### 📋 Supported Formats

PNG, JPG, JPEG, BMP, GIF, WEBP, TIFF

### 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Python 3.12 | Core language |
| Tkinter | GUI framework |
| Pillow | Image processing and PDF conversion |
| tkinterdnd2 | Drag & drop support |
